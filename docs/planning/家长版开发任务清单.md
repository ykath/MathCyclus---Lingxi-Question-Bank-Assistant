# MathEx 家长版 · 开发任务清单（M1–M4）

> 版本：v1.0
> 日期：2026-10-01
> 依据：[PRD.md](../PRD.md)、现有代码结构（`question_bank_app.py` / `services/` / `utils/`）、`docs/planning/` 数据库重构与导入管线规划
> 使用方式：每个任务有唯一 ID（如 `M1-T03`），可直接登记到项目管理工具；标注 🔒 的为阻塞依赖，需前置完成。

---

## 通用约定

- **工期单位**：人日（d），按单人兼职开发估算，仅作排期参考。
- **分支策略**：每个里程碑一个集成分支 `feat/mX-*`，任务完成后合并；M1 开始前先冻结当前稳定版（M0）。
- **验收环境**：Windows 本机 + Python 3.12 + 现有 .venv；涉及打印的任务需在「有 LaTeX」和「无 LaTeX」两种环境分别验证。

### 依赖关键提示

- **数据库 schema（M0-T04）** 是一切的前提，务必先行且字段一次想全（含 MistakeRecord / PrintJob 系列）。
- **打印双通道验证（M3-T01）** 是最大技术风险，建议提前到 M2 期间并行做 spike，不等 M3 开工。
- **PDF 导入（M4-T04）** 范围容易膨胀，严格控制为「切页+切题+草稿」最小闭环，MinerU 只作可选。
- 语义搜索、统计热力图、教研字段界面化**已明确不做**，开发中遇到相关旧代码只做隐藏，不做删除（保留回滚余地）。
