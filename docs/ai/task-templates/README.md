# 任务模板

本目录把常见工作拆成可复用的任务合同。每次开始一项工作时，先复制最接近的模板到任务记录或 issue 中，再补齐项目专属信息。

模板统一回答四件事：

1. 输入是什么，哪些数据可以被读取。
2. 预期输出是什么，输出落在哪里。
3. 哪些操作禁止执行。
4. 用什么检查判断任务完成。

这些模板是执行约束，不替代当前代码、`db/schema.sql`、正式迁移文件和 `docs/ai/hard-rules.md`。

## 使用规则

- 先确认任务属于哪一种模板；跨多个模板时，分别记录每一部分的验收结果。
- 模板中的“必须”是交付门槛；无法满足时要在交付说明中明确写出原因。
- 任务记录应放在本地报告、issue 或开发日志中，不把个人路径、API Key、真实题库数据写入模板。
- 同一任务的输入、模型、提示词版本、文件哈希和人工决策，后续应沉淀到可恢复任务摘要中。
