# 批量题目录入任务合同

## 输入

- TeX、文本、图片或 PDF 形成的一个或多个题目草稿。
- 题型、知识板块、来源类型、年份、卷别、试卷名称、题号和教材/专题信息。
- 已确认的来源候选和当前数据库中的重复题检查结果。

## 预期输出

- 每题一个可编辑、可审核的草稿。
- 题干、选项、答案、解析、图片资源和来源关系分别可校订。
- 完全相同、高度相似、来源位置冲突和语义推荐分开显示。
- 人工逐题确认后，才写入正式题库、关系表和修订记录。

## 必须遵守

- 稳定 `question_id` 是题目身份；年份、题号和文件名不能代替题目 ID。
- 共享来源只在来源确实一致时继承；每题识别出不同来源时必须分组确认。
- 选择题使用 `choices` 和 `\choice{{$...$}}`，保留项目既有 TeX 结构。
- 未标记来源允许年份、卷别和试卷名称为空，不用虚假来源填充。
- 修改已批准草稿后必须撤销旧批准状态，重新进入审核。

## 禁止事项

- 不自动删除或合并重复题。
- 不把相似题候选直接当成重复题入库。
- 不为了补齐字段而替题目编写原图中不存在的答案或解析。
- 不让 Local API 或页面脚本绕过人工审核直接批准。

## 验收检查

- 题型、知识板块、来源和题号能在预览中正确显示。
- TeX 环境、花括号、选项数量和图片引用通过检查。
- 每题的审核状态、重复/相似标记和来源关系可追溯。
- 录入一个题、批量录入和同卷录入不能破坏已有数据流。
- 运行对应录入 UI、草稿审核、来源匹配和相似度 smoke。
